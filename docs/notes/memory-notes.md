# 实模式内存与文本显存

本文整理 PC 兼容机学习过程中常见的地址范围。具体布局随机器与 BIOS 而变化；本项目的加载地址见 [当前引导流程](../boot-flow.md)。

## 低端内存布局

| 物理地址范围 | 常见用途 |
| --- | --- |
| `0x00000`–`0x003FF` | 实模式中断向量表 |
| `0x00400`–`0x004FF` | BIOS 数据区 |
| `0x00500`–传统内存顶部 | 常规内存；顶部可能保留扩展 BIOS 数据区 |
| `0xA0000`–`0xAFFFF` | VGA 图形显存窗口 |
| `0xB0000`–`0xB7FFF` | 单色文本显存窗口 |
| `0xB8000`–`0xBFFFF` | 彩色文本显存窗口 |
| `0xC0000`–`0xEFFFF` | 扩展 ROM、设备映射或保留区域 |
| `0xF0000`–`0xFFFFF` | 传统系统 BIOS 映射区域 |

扩展 BIOS 数据区的起点不是固定常量。上述区域用于理解传统 PC 内存布局，不能直接当作可分配内存清单。

## 80 × 25 文本模式

在常见的彩色文本模式中，显存基址为 `0xB8000`。每个字符格占两个字节：字符编码和颜色属性。

```text
字符字节偏移 = (行号 × 80 + 列号) × 2
属性字节偏移 = 字符字节偏移 + 1
一屏使用字节数 = 80 × 25 × 2 = 4000
```

行号和列号从 0 开始。文本显示页的数量与显示模式、显示起始地址有关；不能由“一屏 4000 字节”推导出写越界会自动回绕。

MBR 用 `ES=0xB800` 访问彩色文本显存。Loader 进入保护模式后，用基址为 `0xB8000` 的段描述符和 `GS` 访问同一显存区域。

## 复位与引导入口

- 8086 的复位入口与后续 32 位处理器的复位机制存在区别，不能把两者的初始寄存器状态直接混用。
- 在本项目的 BIOS 磁盘引导流程中，MBR 的加载地址为 `0x7C00`。
- 现代 UEFI 的原生启动流程与本项目使用的 BIOS 引导流程不同。
