# 当前源码的引导流程

本文只描述 [`mbr.asm`](../src/boot/mbr.asm) 和 [`loader.asm`](../src/boot/loader.asm) 中的现有实现。

```mermaid
flowchart LR
    BIOS[BIOS] --> MBR[MBR · 0x7C00]
    MBR --> Key[显示信息并等待按键]
    Key --> ATA[读取 LBA 1]
    ATA --> Loader[Loader · 0x0900]
    Loader --> GDT[开启 A20 / 装载 GDT]
    GDT --> PM[进入 32 位保护模式]
    PM --> VGA[VGA 字符输出 / 循环停留]
```

## MBR

1. 以 `org 0x7c00` 汇编，初始化段寄存器与栈。
2. 通过 BIOS `int 0x10` 和 VGA 文本显存输出引导信息。
3. 通过 BIOS `int 0x16` 等待按键。
4. 通过 ATA 端口 `0x1F0`–`0x1F7` 发出读取命令，从 LBA 1 读取一个扇区到 `0x0900`。
5. 跳转到 Loader。引导扇区末尾使用 `55 AA` 签名。

## Loader

1. 在实模式下通过 BIOS 输出 `boot ok` 和 `loading...`。
2. 通过端口 `0x92` 开启 A20。
3. 装载 GDT，其中包含空描述符、代码段、数据段和显存段。
4. 设置 `CR0.PE`，通过远跳转切换到 32 位代码段。
5. 更新数据段、栈段和显存段寄存器，通过 `GS` 写入 VGA 文本显存。
6. 在 `jmp $` 循环处停留。

## 地址约定

| 地址 / 位置 | 用途 |
| --- | --- |
| LBA 0 | 512 字节 MBR |
| LBA 1 | Loader 所在扇区 |
| `0x7C00` | MBR 编译与执行入口、实模式初始栈顶 |
| `0x0900` | Loader 加载地址、保护模式初始栈顶 |
| `0xB8000` | VGA 彩色文本显存基址 |

当前代码未实现 IDT、分页、任务调度或文件系统，也没有继续加载内核文件。原始笔记中涉及的其他内核地址属于学习资料，不能替代本页的源码约定。

切换到保护模式前尚未通过 `cli` 关闭可屏蔽中断，也没有建立保护模式的 IDT。如果此时 IF 已开启，硬件中断可能导致异常乃至三重故障重启。上面的流程描述源码的执行路径，不代表演示已验证能持续停留运行。
